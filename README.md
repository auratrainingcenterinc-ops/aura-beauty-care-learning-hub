# AURA BEAUTY CARE LEARNING HUB
## BEAUTY CARE (NAIL CARE) SERVICES NC II

**Organization:** AURA TRAINING AND ASSESSMENT CENTER INC.  
**Tagline:** "Learn the Skills. Master the Art. Build Your Future."

## 🚀 Getting Started
1. Install dependencies: `npm install`
2. Set up database: `npx prisma db push`
3. Create .env file with DATABASE_URL and ADMIN_CREDENTIALS
4. Start development server: `npm run dev`
5. Deploy to Netlify: Connect repository and deploy

## 🏗️ Technology Stack
- **Frontend:** Next.js 14 (App Router), TypeScript, Tailwind CSS
- **Backend:** Node.js API Routes
- **Database:** PostgreSQL (Prisma ORM)
- **Deployment:** Netlify
- **Progress Storage:** Browser LocalStorage (Public users)
- **Certificate Generation:** jsPDF

## 📚 Course Structure
- **15 Competency Units** organized in 3 categories
- **Basic Competencies (Units 1-9):** Workplace communication, safety, innovation, etc.
- **Common Competencies (Units 10-13):** Client relationships, performance, quality
- **Core Competencies (Units 14-15):** Manicure/Pedicure & Hand/Foot Spa (Special emphasis)

## 🔑 Key Features
- Public access (No registration/login for students)
- Mobile-first responsive design
- LocalStorage progress tracking
- Unit-based quizzes + Comprehensive mock exam
- Certificate of completion (PDF download)
- Administrator panel (Secure)
- TESDA compliance disclaimer included

## 📁 Directory Structure
- `src/app/` - Next.js routes and pages
- `src/components/` - Reusable UI components
- `src/content/` - Learning content for 15 units
- `src/lib/` - Database and utility functions
- `public/` - Images, videos, PDFs
- `prisma/` - Database schema

## 🎨 Design System
- **Colors:** Purple (#6B46C1), Lavender (#E0E7FF), White (#FFFFFF)
- **Typography:** Inter (Sans), Playfair Display (Serif)
- **Mobile-first:** Responsive across all devices
- **Accessibility:** WCAG compliant

## 🛠️ Administrator Functions
- Manage 15 competency units
- Add/edit modules and lessons
- Upload learning materials (PDFs, videos, images)
- Create/edit quizzes and exams
- View analytics and export records
- Secure authentication required

## 🎓 Public Learning Experience
1. Open website → Click START LEARNING
2. Select category (Basic/Common/Core)
3. Choose competency unit
4. Open lessons (Read, Watch, Download)
5. Take quizzes (Automatic scoring)
6. Track progress (LocalStorage)
7. Generate certificate (Optional)
